# FOG

基于 Godot 4.5 制作的游戏项目。

## 项目信息

| 项目 | 内容 |
| --- | --- |
| 项目名 | FOG |
| 引擎版本 | Godot 4.5 |
| 渲染方式 | GL Compatibility |
| 项目标识 | `com.mist.game` |
| 主场景 | `res://主界面/主界面.tscn` |
| 设计分辨率 | 1280 × 720 |
| 作者 | 虹（Nafuboay） |
| License | MIT |

## 自动加载（Autoload）脚本

在 `project.godot` 中注册的全局单例：

| 全局名 | 脚本路径 |
| --- | --- |
| `Danmaku` | `res://全局/提示弹幕.gd` |
| `数据管理` | `res://全局/数据管理.gd` |

## 快速开始

1. 安装 Godot 4.5 或更高版本的 4.x 编辑器（官网 https://godotengine.org ）。
2. 打开 Godot 编辑器 → 导入 → 选择本仓库根目录下的 `project.godot`。
3. 按 `F5` 运行游戏。
